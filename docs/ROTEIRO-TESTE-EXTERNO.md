# Roteiro de teste com público externo

Objetivo: verificar se uma pessoa que não participou do projeto consegue usar a API sem orientação da equipe.

## Antes do teste

1. Envie apenas a URL pública e o link do README.
2. Não explique as rotas antes da pessoa tentar.
3. Peça autorização para registrar comentários de forma anônima por vínculo/papel.

## Tarefas

1. Descobrir quais datasets a API oferece.
2. Consultar os indicadores de um município em 2025.
3. Encontrar as rodovias com maior número de acidentes em 2025.
4. Encontrar os trechos críticos.
5. Explicar, com as próprias palavras, uma limitação dos dados indicada no README.

## Perguntas depois do uso

- Em qual etapa você travou?
- Algum nome de rota ou parâmetro ficou confuso?
- O que você esperava encontrar e não encontrou?
- Você usaria essa API em um trabalho, matéria, pesquisa ou aplicação? Para quê?
- De 0 a 10, quão fácil foi começar sem ajuda?

## Registro

Crie um arquivo em `evidencias/AAAA-MM-DD-teste-externo-NN.md` contendo:

- vínculo da pessoa, sem nome completo;
- data e canal;
- tarefas concluídas;
- onde houve dificuldade;
- uma ou duas frases literais autorizadas;
- alteração decidida pela equipe a partir do teste.

Depois adicione uma linha correspondente no `evidencias.csv`.
