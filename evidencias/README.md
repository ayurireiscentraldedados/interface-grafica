# Evidências

Esta pasta recebe somente evidências reais, com data no nome.

Exemplos:

- `2026-10-15-teste-externo-01.md`
- `2026-11-08-feedback-email.pdf`
- `2026-11-12-resumo-acessos.png`

Não registrar nome completo, telefone, e-mail ou outros dados pessoais de usuários externos sem autorização explícita. No `evidencias.csv`, prefira vínculo/papel: “estudante de jornalismo”, “pesquisador de mobilidade”, “desenvolvedor externo”.
